# Cairn v0.33.0 Hard-Cut Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release the provider-neutral backend as Cairn `0.33.0`, migrate old derived state once, and remove all permanent Claude/Haiku compatibility branches.

**Architecture:** A safe versioned migration owns the one-time state cutover. Production model and status paths then understand only the provider-neutral contract. The shared runner enforces Cursor isolation at its boundary, and availability checks resolve the configured provider rather than any installed provider.

**Tech Stack:** TypeScript, Node.js subprocess/filesystem APIs, Zod, pnpm workspace smokes.

## Global Constraints

- Preserve the contributor's shared tri-host architecture.
- Use `gpt-5.3-codex-spark` for bounded Codex work.
- Do not run live Claude, Cursor, or Codex requests.
- Preserve unrelated dependency-version edits already present in package manifests.
- Use `0.33.0` as the migration and package-version boundary.
